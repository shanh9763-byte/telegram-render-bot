# 🤖 Telegram Bot – DNS Checker & Chi Tiêu Gia Đình

Bot Telegram đa chức năng chạy trên Render.com (FREE 24/7):

- **Nhắn riêng (PRIVATE CHAT)** → Kiểm tra DNS / CNAME của tên miền  
- **Trong nhóm (GROUP CHAT)** → Ghi lại chi tiêu vợ chồng, thống kê ngày / tháng  

Bot được viết theo chuẩn **python-telegram-bot v20** (Application, async), chạy ổn định trên Render.
